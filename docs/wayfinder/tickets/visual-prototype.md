# Visual prototype of bands and regime channel

## Question

What should it look like: one 1-minute chart showing VWAP with the 1-sigma and 3-sigma bands marked, and one daily chart with the four regime states marked, both over recent EURUSD data? The charts give the user something concrete to react to before the signal rule and the schema harden.

## Resolution

The page is [dashboard/prototype.html](../../../dashboard/prototype.html), regenerated by [scripts/generate_prototype_page.py](../../../scripts/generate_prototype_page.py). It exceeds the question: all three symbols, not only EURUSD, each with a 1m band chart over the last four complete sessions, a 1d regime chart over the last 260 bars, a signal tape joining daily band-position counts to the regime ribbon, a position-by-regime cross-tab, and window stats over the trailing 365 days. The generator recomputes from `data/processed` at run time, so the page never reads gitignored `signals/`.

Observation mode only: 1-sigma containment is reported as containment, not as a win rate, and every record keeps `action: "observe"`. Dashboard accents stay amber, green, red; findings stay monochromatic blue.

Verified 2026-09-23 by structural checks, accepted by the user in place of a visual preview: 12 SVGs across three symbol sections, page closes with `</html>`, no `NaN` or `undefined` in output, band-position shares render non-zero and sum to 100 (EURUSD 0.8 / 28.0 / 42.6 / 28.0 / 0.7), and 30 tests pass. One bug found and fixed during checks: the position-distribution lookup keyed on display labels instead of internal names and rendered all zeros.

Dashboard wiring: the Backtest link joins the nav in index, findings, and the shared NAV constant; index gains an evidence link card, the KPI reads `1 year observation view`, and `weekly_refresh.run_cycle` regenerates the page after each engine run, non-fatal on failure.
